# Школа сервиса: обучение персонала Café Leffe

Демо сервиса обучения персонала в формате Telegram Mini App. Автор — Роман Окшин.

## Что внутри

- **Регистрация по QR-приглашению** ресторана, подтверждение менеджером.
- **Маршрут по должности**: хостес, официант, бармен, раннер, повар — у каждой свой набор станций.
- **7 станций**: встреча гостя, 7 шагов сервиса, продажи и допродажа, уборка стола, бар: бельгийское пиво, морепродукты и стейки, гигиена на кухне. В каждой урок-раскадровка, шпаргалка, тест из 5 вопросов и QR-наклейка.
- **Тренажёр кассы** (`pos.html`): 4 уровня — простой заказ, стейк с прожаркой и соусом, разные прожарки и сдача, проверка возраста гостя.
- **Баллы, уровни, рейтинг смен, достижения.**
- **Бот** с ответами на частые вопросы.
- **Экран менеджера**: заявки, прогресс новичков и станций, результаты обучения, аттестация по чек-листу должности (90% пунктов, критичные — без ошибок).

Данные условные и хранятся только на телефоне (localStorage). Меню и цены в тренажёре условные.

## Как подключить к Telegram

1. Опубликуйте папку через GitHub Pages (Settings → Pages → ветка `main`).
2. Создайте бота в @BotFather и добавьте Mini App со ссылкой на страницу.
3. Имя бота указано в `index.html` в строке `var BOT='Training_trainerBot';`: QR-коды открывают уроки прямо в Telegram.
